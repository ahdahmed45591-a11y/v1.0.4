========================================================================
           GUIDE DE DEMARRAGE RAPIDE — BAOU FINANCE v1.0.4
========================================================================
Commandes a executer dans des terminaux separes pour lancer le projet.
------------------------------------------------------------------------

METHODE 1 — AUTOMATIQUE (RECOMMANDEE) : Double-cliquez sur demarrer_local.bat

------------------------------------------------------------------------
METHODE 2 — MANUELLE (terminaux separes)
------------------------------------------------------------------------

1. LE BACKEND (Express / Node.js + SQLite)
------------------------------------------------------------------------
Ouvrez un terminal :

   cd d:\Antigravity\projet\finance\v1.0.3\backend
   npm install
   node server.js

* Accessible sur  : http://localhost:3001
* Base de donnees : backend\data\baou_finance.db  (SQLite, local)
* Fichiers uploades: backend\uploads\             (CNI, Selfie, PDF...)

------------------------------------------------------------------------
2. LE PORTAIL ADMINISTRATEUR (React / Vite)
------------------------------------------------------------------------
Ouvrez un deuxieme terminal :

   cd d:\Antigravity\projet\finance\v1.0.3\admin
   npm install
   npm run dev

* Accessible sur  : http://localhost:3000
* Login Admin     : admin@elephantbourse.ci / admin2024

------------------------------------------------------------------------
3. TUNNEL NGROK (pour telephone Android physique)
------------------------------------------------------------------------
Ouvrez un troisieme terminal :

   ngrok http 3001

* Copiez l'URL  https://xxxx.ngrok-free.app
* Dans l'app mobile : Engrenage -> URL = https://xxxx.ngrok-free.app/api/

------------------------------------------------------------------------
4. BASE DE DONNEES SQLITE (100% LOCAL, PAS D'INTERNET REQUIS)
------------------------------------------------------------------------
La base SQLite est initialisee et migree AUTOMATIQUEMENT au demarrage.
Tables : users, transactions, holdings, messages, notifications
Colonnes documents : cni_recto_url, cni_verso_url, selfie_url, proof_address_url

------------------------------------------------------------------------
5. L'APPLICATION MOBILE ANDROID (Android Studio)
------------------------------------------------------------------------
* Ouvrez : d:\Antigravity\projet\finance\v1.0.3  dans Android Studio
* Attendez la synchronisation Gradle (~2-3 min la 1ere fois)
* Connectez votre telephone Android ou lancez un emulateur
* Configurez l'URL via l'icone ENGRENAGE sur l'ecran de connexion :
  - Emulateur    : http://10.0.2.2:3001/api/
  - Telephone LAN: http://[VOTRE_IP]:3001/api/  (ipconfig pour trouver IP)
  - Via Ngrok    : https://xxxx.ngrok-free.app/api/
