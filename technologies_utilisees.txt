========================================================================
          BAOU FINANCE v1.0.4 — TECHNOLOGIES ET COMPOSANTS
========================================================================

Liste complete des technologies, frameworks et outils utilises dans
le projet BAOU Finance (Bourse Africaine / BRVM — Cote d'Ivoire).

------------------------------------------------------------------------
1. APPLICATION MOBILE (Android Native)
------------------------------------------------------------------------
Langage           : Kotlin (100% natif, aucun framework cross-platform)
UI Framework      : Jetpack Compose (UI declarative moderne)
Architecture      : MVVM — ViewModels, StateFlow, Coroutines (async)
Navigation        : Compose Navigation (NavHostController)
Client HTTP       : Retrofit 2 + OkHttp3 + Gson (appels API REST)
Stockage local    : SharedPreferences (token JWT, URL serveur)
Upload fichiers   : Base64 encoding vers /api/auth/upload-document
Download PDF      : MediaStore API (Android 10+ Scoped Storage)
Design System     : Material Design 3 (couleurs, typographie, icones)
Permissions       : CAMERA, READ_MEDIA_IMAGES, WRITE_EXTERNAL_STORAGE
Min SDK           : Android 8.0 (API 26)
Target SDK        : Android 14 (API 34)
Build Tool        : Gradle 9.3.1 + Android Gradle Plugin 9.1.1

Ecrans principaux :
  - LoginScreen         : Connexion email/PIN avec Google simulee
  - OnboardingScreen    : Inscription + KYC (upload CNI, Selfie, CIE)
  - HomeScreen          : Portfolio, solde, acces rapide
  - MarketScreen        : Cours BRVM en temps reel (66 actions)
  - BourseScreen        : Achat/Vente d'actions BRVM
  - PortfolioScreen     : Positions ouvertes, historique
  - ProfileScreen       : Profil, Documents & Contrats, telechargement PDF
  - MessagesScreen      : Chat bidirectionnel avec l'admin (polling 4s)
  - SupportScreen       : Tickets de support envoyes a l'admin

------------------------------------------------------------------------
2. BACKEND API (Node.js / Express)
------------------------------------------------------------------------
Runtime           : Node.js (v18+)
Framework Web     : Express.js
Middleware        : CORS, express.json (limite 50MB pour Base64)
Sessions          : In-memory token store (Map JavaScript)
Upload fichiers   : fs.writeFileSync + Buffer.from(base64) -> backend/uploads/
Fichiers statiques: express.static -> /uploads (servis sur port 3001)
CSV Parser        : Chargement cours BRVM depuis fichiers .daily.csv locaux
Messagerie        : Stockage en memoire (tableau messages)
Notifications     : Generees automatiquement lors des actions admin

Routes principales :
  POST /api/auth/login            : Connexion utilisateur
  POST /api/auth/register         : Inscription nouveau client
  POST /api/auth/upload-document  : Upload CNI, Selfie, CIE/SODECI (Base64)
  GET  /api/admin/users           : Liste clients avec URLs documents
  GET  /api/admin/messages        : Messages chat admin<->client
  POST /api/admin/messages/send   : Admin envoie message a un client
  GET  /api/stocks                : Liste 66 actions BRVM
  POST /api/transactions          : Creer une transaction (depot/ordre)
  PATCH /api/transactions/:id     : Valider/Rejeter une transaction

------------------------------------------------------------------------
3. PORTAIL ADMINISTRATEUR (Web React)
------------------------------------------------------------------------
Framework         : React 18 + TypeScript
Build Tool        : Vite 6 (HMR, build optimise)
Styling           : Vanilla CSS + classes Tailwind-like inline
Icones            : Lucide React
Etat global       : useState, useEffect (pas de Redux)
Fonctionnalites   :
  - Tableau de bord avec statistiques en temps reel
  - Gestion Utilisateurs : fiche complete, documents, KYC
  - Visualisation et telechargement des photos clients (modal plein ecran)
  - Envoi de messages aux clients
  - Validation/Rejet des transactions
  - Support et tickets clients
  - Notifications avec navigation contextuelle

Port par defaut   : 3000 (configure dans vite.config.ts)

------------------------------------------------------------------------
4. BASE DE DONNEES SQLITE LOCALE (100% hors ligne)
------------------------------------------------------------------------
Moteur            : SQLite3 (via npm package 'sqlite3')
Fichier           : backend/data/baou_finance.db
Migration         : Automatique au demarrage (ALTER TABLE si colonne manquante)

Schema des tables :
  users :
    id, name, email, password, role, level, avatar
    whatsapp, birthDate, profession, residence
    kyc, balance, portfolioValue, joinedAt
    identityDocStatus, proofOfAddressStatus, signatureStatus
    cni_recto_url, cni_verso_url, selfie_url, proof_address_url   [NEW v1.0.4]

  transactions :
    id, user_id, user_name, ticker, company, type
    quantity, price, total, fees, tva, grand_total
    status, payment_ref, payment_method, rejection_reason, submitted_at

  holdings :
    id, user_id, ticker, company, quantity, avg_price, current_price, total_value

  messages :
    id, userId, userName, sender, text, time

  notifications :
    id, type, title, message, time, read, userId, action

------------------------------------------------------------------------
5. BASE DE DONNEES CLOUD (Supabase — optionnel)
------------------------------------------------------------------------
Moteur            : PostgreSQL (heberge sur Supabase Cloud)
SDK               : @supabase/supabase-js
Fonctionnement    : Miroir de SQLite. Synchronisation automatique si Internet.
Tables cloud      : users, transactions, holdings (meme schema que SQLite)
