========================================================================
              BAOU FINANCE - INSTRUCTIONS DE DEMARRAGE v1.0.4
========================================================================

Ce projet est compose de trois composants :
  1. Un backend Node.js/Express (API REST + SQLite locale + uploads fichiers)
  2. Un portail administrateur React/Vite (gestion KYC, documents, messages)
  3. Une application mobile Android native (Kotlin + Jetpack Compose)

Toutes les donnees sont persistees LOCALEMENT dans SQLite (100% hors ligne).
Un miroir Supabase Cloud est disponible en option si vous avez Internet.

------------------------------------------------------------------------
METHODE RAPIDE (1 CLIC) — RECOMMANDEE
------------------------------------------------------------------------
Double-cliquez sur : demarrer_local.bat
Ce script demarre automatiquement les 3 services et ouvre le navigateur.

------------------------------------------------------------------------
1. ETAPE 1 : LE BACKEND EXPRESS + SQLITE (Port 3001)
------------------------------------------------------------------------
Le backend centralise toute la logique metier :
  - Authentification clients (JWT sessions)
  - Upload et stockage des documents (CNI, Selfie, CIE/SODECI)
  - Base SQLite : backend\data\baou_finance.db
  - Fichiers uploades : backend\uploads\

Commandes a executer :
   cd backend
   npm install
   node server.js

-> Le backend demarre sur : http://localhost:3001
-> Les cours BRVM sont charges depuis les fichiers CSV locaux.
-> La base SQLite est initialisee automatiquement au demarrage.
-> La migration des colonnes (CNI, selfie, etc.) est automatique.

------------------------------------------------------------------------
2. ETAPE 2 : LE PORTAIL ADMINISTRATEUR React/Vite (Port 3000)
------------------------------------------------------------------------
Le portail admin permet a M. Cisse de :
  - Valider / Rejeter les transactions (depot Wave, BUY/SELL)
  - Consulter et TELECHARGER les documents clients (CNI, Selfie, CIE)
  - Envoyer des messages aux clients
  - Gerer les statuts KYC
  - Recevoir et traiter les tickets de support

Commandes a executer :
   cd admin
   npm install
   npm run dev

-> Accessible sur : http://localhost:3000
-> Identifiants Administrateur :
   - Email       : admin@elephantbourse.ci
   - Mot de passe: admin2024

------------------------------------------------------------------------
3. ETAPE 3 : L'APPLICATION MOBILE ANDROID (Kotlin / Jetpack Compose)
------------------------------------------------------------------------
L'application mobile se connecte au backend local via Wi-Fi ou via Ngrok.

Lancement via Android Studio :
- Ouvrez le dossier racine du projet dans Android Studio.
- Attendez la synchronisation Gradle (peut prendre 2-3 minutes).
- Lancez l'application sur votre telephone Android ou un emulateur.

Configuration de l'URL du serveur (OBLIGATOIRE pour vrai telephone) :
  * Sur l'ecran de connexion, cliquez sur l'icone ENGRENAGE (haut droite).
  * Saisissez l'URL correspondant a votre cas :
    - Emulateur local       : http://10.0.2.2:3001/api/
    - Telephone Wi-Fi local : http://[VOTRE_IP_LAN]:3001/api/
                              (trouver votre IP : ipconfig dans cmd)
    - Telephone via Ngrok   : https://xxxx.ngrok-free.app/api/
  * Cliquez sur "Enregistrer". L'app memorise l'adresse automatiquement.

Obtenir l'URL Ngrok (pour vrai telephone hors Wi-Fi local) :
  1. Lancez demarrer_local.bat
  2. Dans la fenetre "BAOU Ngrok Tunnel", copiez l'URL https://
  3. Collez-la dans les Parametres de l'application + ajoutez /api/

------------------------------------------------------------------------
4. UPLOAD DE DOCUMENTS (NOUVEAUTE v1.0.4)
------------------------------------------------------------------------
Depuis l'application mobile, l'utilisateur peut uploader :
  - CNI Recto  (photo camera ou galerie)
  - CNI Verso  (photo camera ou galerie)
  - Selfie visage (photo camera ou galerie)
  - Facture CIE/SODECI (fichier galerie)

-> Les fichiers sont convertis en Base64 et envoyes au backend.
-> L'admin les voit immediatement dans "Gestion des Utilisateurs".
-> L'admin peut les CONSULTER (modal plein ecran) et les TELECHARGER.
-> Les photos sont stockees dans : backend\uploads\

------------------------------------------------------------------------
5. MESSAGERIE ADMIN <-> CLIENT (NOUVEAUTE v1.0.4)
------------------------------------------------------------------------
-> L'admin peut envoyer un message a n'importe quel client depuis
   "Gestion des Utilisateurs" -> fiche client -> "Envoyer un message".
-> Le client recoit le message en temps reel dans l'ecran "Messages"
   de son application mobile (actualisation automatique toutes les 4s).
-> Le client peut repondre depuis l'application mobile.

------------------------------------------------------------------------
6. DEPOTS VIA WAVE CI
------------------------------------------------------------------------
- Dans l'app mobile : Portfolio -> Deposer
- Saisissez un montant et choisissez "Wave CI".
- L'application ouvre le lien de paiement officiel :
  https://pay.wave.com/m/M_ci_XRkfDq_9M8GP/c/ci/?src=p
- La transaction est enregistree automatiquement et le solde mis a jour.
