5. CONFIGURATION URL MOBILE (OBLIGATOIRE pour telephone physique)
-------------------------------------------------------------------------------
Sur l'ecran de connexion de l'app, cliquez l'icone ENGRENAGE (haut droite) :

  Cas 1 — Emulateur Android Studio  : http://10.0.2.2:3001/api/
  Cas 2 — Telephone sur meme Wi-Fi  : http://[VOTRE_IP_LAN]:3001/api/
           (trouver votre IP locale : ouvrir cmd -> taper : ipconfig)
  Cas 3 — Telephone via Ngrok       : https://xxxx.ngrok-free.app/api/

Lancer Ngrok : ouvrez un terminal -> ngrok http 3001
Copiez l'URL https://xxxx.ngrok-free.app -> collez dans Parametres + /api/

7. COMMENT LANCER L'ECOSYSTEME COMPLET
-------------------------------------------------------------------------------
• Methode 1 — Automatique (1 Clic) :
  Double-cliquez sur : demarrer_local.bat
  Demarre le backend (3001) + Admin React (3000) + Ngrok + ouvre le navigateur.

  Terminal 1 : cd backend  -> npm install -> node server.js
  Terminal 2 : cd admin    -> npm install -> npm run dev
  Terminal 3 : ngrok http 3001

  docker-compose up --build
