========================================================================
          BAOU FINANCE v1.0.4 — COMMANDES DE LANCEMENT
========================================================================

Copiez-collez les commandes suivantes dans vos terminaux.
Ou double-cliquez directement sur : demarrer_local.bat  (plus simple !)

------------------------------------------------------------------------
1. BACKEND NODE.JS + SQLITE (Port 3001)
------------------------------------------------------------------------
cd d:\Antigravity\projet\finance\v1.0.3\backend
npm install
node server.js

-> API disponible sur  : http://localhost:3001
-> SQLite local        : backend\data\baou_finance.db
-> Uploads documents   : backend\uploads\

------------------------------------------------------------------------
2. PORTAIL ADMINISTRATEUR REACT (Port 3000)
------------------------------------------------------------------------
cd d:\Antigravity\projet\finance\v1.0.3\admin
npm install
npm run dev

-> Admin disponible sur : http://localhost:3000
-> Login : admin@elephantbourse.ci / admin2024

------------------------------------------------------------------------
3. TUNNEL NGROK (telephone Android physique via Internet)
------------------------------------------------------------------------
ngrok http 3001

-> Copiez l'URL https://xxxx.ngrok-free.app
-> Dans l'app mobile : Engrenage -> https://xxxx.ngrok-free.app/api/

------------------------------------------------------------------------
4. APPLICATION MOBILE ANDROID (Android Studio)
------------------------------------------------------------------------
-> Ouvrez le dossier du projet dans Android Studio
-> Build -> Run 'app'  (ou Shift+F10)

URL selon votre cas :
  Emulateur local       : http://10.0.2.2:3001/api/
  Telephone Wi-Fi local : http://[VOTRE_IP]:3001/api/
  Telephone via Ngrok   : https://xxxx.ngrok-free.app/api/

Trouver votre IP locale (Windows) :
  -> Ouvrez cmd et tapez : ipconfig
  -> Cherchez "Adresse IPv4" sous votre carte Wi-Fi

------------------------------------------------------------------------
5. BUILD DE LA BASE DE DONNEES SQLITE (automatique)
------------------------------------------------------------------------
La base SQLite est creee et migree automatiquement au demarrage du backend.
Aucune commande supplementaire requise.
Emplacement : backend\data\baou_finance.db

Pour remettre la base a zero (optionnel) :
  del d:\Antigravity\projet\finance\v1.0.3\backend\data\baou_finance.db
  (La base sera recreee au prochain demarrage du backend)

------------------------------------------------------------------------
6. CONSTRUIRE L'APK ANDROID LOCALEMENT
------------------------------------------------------------------------
cd d:\Antigravity\projet\finance\v1.0.3
.\gradlew assembleDebug

-> APK genere dans : app\build\outputs\apk\debug\app-debug.apk

Telecharger l'APK depuis GitHub Actions :
-> https://github.com/ahdahmed45591-a11y/v1.0.4/actions
-> Dernier workflow reussi -> Artifacts -> app-debug

------------------------------------------------------------------------
7. DOCKER (optionnel)
------------------------------------------------------------------------
cd d:\Antigravity\projet\finance\v1.0.3
docker-compose up --build
